# private/

Notes that name real places, days, devices and paths — the material this repo
must not carry once it is public. **Nothing here is committed** (see the
`/private/*` rule in `.gitignore`). The directory exists so those files stay on
disk where the owner can still read them, and so a committed document can refer
to them with a predictable home.

This README is the one tracked file here, so the convention travels with the
repo.

Current contents:

- `TODO-history.md` — a verbatim archive of `TODO.md` as it stood on
  2026-09-22, moved out of `docs/` on 2026-10-07. It is a travel history in
  prose; the live list is now a private GitHub Project, which `TODO.md` points
  at.
